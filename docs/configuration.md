# Configuration reference

Configuration is read from process environment variables by `src.config`.
Defaults are safe for local Ollama development where shown. `.env.example`
documents the same names, but `.env` is not loaded automatically; load it in
your shell or use your deployment's secret manager.

## Local Ollama + Oracle configuration

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `LLM_PROVIDER` | Yes for live chat | `ollama` | `ollama` or `oci` generation adapter. |
| `EMBEDDING_PROVIDER` | Yes for retrieval | `ollama` | `ollama` or `oci` embedding adapter. |
| `OLLAMA_BASE_URL` | When either provider is Ollama | `http://127.0.0.1:11434` | Ollama local HTTP API base URL. |
| `OLLAMA_TIMEOUT_SECONDS` | No | `120` | Positive request timeout. |
| `LLM_MODEL` | Yes for live generation | `llama3.2:3b` for Ollama | Selected generation model. |
| `EMBEDDING_MODEL` | Yes for retrieval | `nomic-embed-text` for Ollama | Selected embedding model. |
| `EMBEDDING_DIMENSION` | Yes for retrieval | `768` for Ollama | Expected output dimension and Oracle vector-column dimension. |
| `ORACLE_DB_USER` | Yes for live Oracle | none | Oracle database user. |
| `ORACLE_DB_PASSWORD` | Yes for live Oracle | none | Oracle database password; never commit it. |
| `ORACLE_DB_DSN` | Yes for live Oracle | none | Oracle connection descriptor, for example `localhost:1521/FREEPDB1`. |
| `ORACLEVS_TABLE` | Yes for live retrieval | none | Single valid Oracle identifier for the knowledge-vector table. |
| `ORACLE_CONVERSATION_TABLE` | For durable memory | none | Provisioned conversation-memory table identifier. Omit it for process-local memory. |

For `nomic-embed-text`, `EMBEDDING_DIMENSION` must be `768`. Do not reuse a
vector table for vectors generated by a different embedding model, even when
the dimension is the same.

## API and UI configuration

| Variable | Default | Purpose |
| --- | --- | --- |
| `API_BASE_URL` | `http://127.0.0.1:8000` | FastAPI address used by Streamlit's HTTP client. |
| `API_AUTH_MODE` | `development` | `development` uses a server-side demo identity; `required` expects trusted middleware. |
| `API_DEVELOPMENT_USER_ID` | `local-demo-user` | Server-side development identity. It is not supplied by the chat request. |

In `required` mode, deployment authentication middleware must validate a
trusted session/token and set `request.state.authenticated_identity` to an
`AuthenticatedIdentity`. Client-provided `user_id` never authenticates a user;
it is compatibility data and must match the effective identity when present.

## Analytics

| Variable | Default | Purpose |
| --- | --- | --- |
| `ANALYTICS_MODE` | `noop` | `noop` retains no events; `memory` enables a local process-only event sink for the Streamlit analytics view. |

Analytics is best-effort and never controls chat behavior. Memory analytics is
not durable, shared across workers, or intended as production telemetry.

## Optional OCI providers

OCI adapters are retained but are not the default. Set either provider variable
to `oci`, set the matching `LLM_MODEL` or `EMBEDDING_MODEL` and
`EMBEDDING_DIMENSION`, and configure:

| Variable | Purpose |
| --- | --- |
| `OCI_CONFIG_PROFILE` | OCI configuration profile; defaults to `DEFAULT`. |
| `OCI_COMPARTMENT_ID` | Required when an OCI LLM or embedding provider is selected. |
| `OCI_ENDPOINT` | Optional OCI endpoint override. |

Use normal OCI credential/profile mechanisms. Do not put private keys, OCIDs,
or API credentials in tracked documentation or `.env.example`.
